The layout lives in CSS

Five landmarks, one wrapper, zero extra divs. The HTML only says what each part is: header, navigation, main content, sidebar, footer.

Where each part goes is decided by a small map in the stylesheet. On a phone we draw a second map, and the same HTML stacks into one column.
