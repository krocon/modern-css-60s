HTML says what things are

A header, a navigation, an article and a footer. No color classes, no inline styles, no layout hints – just meaning.

CSS decides how they look

Swap the stylesheet with the switch in the top right corner. Grid moves the navigation, custom properties change every color, a different font and different spacing do the rest.

Every design stays responsive

Make the window narrow. Layout lives in the stylesheet, not in the markup – so each theme decides on its own how to behave on small screens.
