Styles for a.button

IDCLSTYPE

.button 010 color: var(--on-brand);
.prose a, .sidebar a, .footer a 011 color: var(--brand);
:is(.prose, .sidebar, .footer) a 011 color: var(--brand);
:where(.prose, .sidebar, .footer) a 001 color: var(--brand);

0-1-1 beats 0-1-0 – the link color wins, the button text disappears.

0-0-1 loses to 0-1-0 – .button wins, no !important needed.
