# B7 · Center anything with one line

**DE:** Alles zentrieren mit einer Zeile

🎬 Episode 014 of 59 · *Modern HTML & CSS in 60 seconds* / Folge 014 von 59 · *Modernes HTML & CSS in 60 Sekunden*  
▶️ Live demo: https://krocon.github.io/modern-css-60s/episodes/b07-center/

## Core CSS (`after.css`)

```css
body,
.avatar,
.icon {
  display: grid;
  place-items: center;
}
```

## Browser support

Baseline widely available · [caniuse](https://caniuse.com/?search=place-items) · [Web Features Explorer](https://web-platform-dx.github.io/web-features-explorer/)

## Links

- MDN: https://developer.mozilla.org/en-US/docs/Web/CSS/place-items

## Run it

No build tools: open `index.html` with a double-click, then use the switch in the top right corner (before/after, light/dark).
